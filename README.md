# Discord Bot Pro

Bot Discord modulaire, sécurisé et prêt pour la production, conçu pour la gestion de serveurs, la modération avancée et les outils d’administration.

Développé avec une architecture scalable inspirée des standards de projets professionnels.

---

## Fonctionnalités

- Système d’administration complet (ban, kick, timeout, unban)
- Outils de modération (suppression de messages, logs)
- Système de blacklist globale inter-serveur
- Système de backup et restauration de serveur
- Régénération de salons
- Embeds temporaires
- Système de logs centralisé
- Anti-raid basique
- Base de données persistante SQLite

---

## Stack technique

- Node.js ≥ 18 (LTS)
- discord.js v14
- better-sqlite3
- dotenv

---

## Architecture

Projet structuré de manière modulaire pour assurer maintenabilité et évolutivité.
